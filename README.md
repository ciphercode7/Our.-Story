# Birthday Letter 💕

GitHub Pages-ready React/Vite version of the birthday website.

## GitHub Pages
1. Create a new GitHub repository.
2. Upload the **contents of this folder** (not the ZIP itself) to the repository.
3. Use the `main` branch.
4. Go to **Settings → Pages** and choose **GitHub Actions** as the source.
5. Push to `main` or run the deployment workflow from **Actions**.
6. GitHub will provide the live Pages URL when deployment finishes.

## Local
Run `npm install`, then `npm run dev`.

The original Spotify embed is preserved. Photos/videos are stored in `public/media/`. The original unlock password is `September10`.
